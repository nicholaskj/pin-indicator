## 英文：插件简介（可直接粘贴）

```
Pin Indicator makes Obsidian's native pinned state visible.

Obsidian keeps a tab from closing when it is pinned, but the only visual cue is
a small icon in the tab bar. On a phone the tab bar is narrow enough that this
cue is effectively invisible — there is no way to tell at a glance whether the
note you are looking at is pinned.

While the current note is pinned, this plugin switches the note's more options
button (⋯) to a lock icon and colors it red. Unpinning restores the original
icon and color. The button keeps working as a menu; only its icon and color
change.

The plugin reads Obsidian's own leaf.pinned flag and stores nothing. No network
access, no telemetry, no filesystem access, no settings.
```

---

## 英文：和已有插件的区别（如果问到重复功能）

```
Several community plugins deal with pinned notes, but none of them surface the
native pinned state in the note itself:

- Pinned Tabs Customizer, Pinned Tabs Row, Pinned Tabs, Shrink pinned tabs,
  Pinned Tab Utils — these change how pinned tabs look or behave in the TAB BAR.
  Pinned Tabs Customizer is also desktop-only.

- Pin Enhancer, Pin Tab Guard, Real Pin — these prevent a pinned tab from being
  closed. They do not display the state.

- Pins Save, Pinned Daily Notes — these restore pins after a restart. They do
  not display the current state.

- Pinned Files, Pinit, Pinup, Pin to Top, Star Pins, Folder Pin, Pinned Notes,
  New Tab Pins — these maintain their OWN pin list and show it in the file
  explorer, ribbon, or a launcher. They are unrelated to Obsidian's native pin.

Obsidian itself renders no pin indicator in a note's view header. On desktop the
tab bar hint exists, but on mobile that hint is effectively invisible. This
plugin fills that specific gap.

It is not a fork. It inherits no code from any existing plugin.
```
