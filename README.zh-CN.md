# Pin Indicator · 笔记锁定指示器

**[English](README.md) | [简体中文](README.zh-CN.md)**

笔记处于锁定状态时，在右上角的「更多选项」按钮上显示一个锁图标。

![已锁定](./images/pinned.png)

---

## 解决什么问题

Obsidian 的**锁定**功能（英文叫 Pin）作用在标签页上，防止标签被误关。但唯一的状态提示只是标签栏里一个很小的图标。

手机屏幕窄，标签栏被压缩，那个图标基本看不见 —— 你没法一眼判断当前这篇笔记到底锁没锁。

## 这个插件做什么

当前笔记**已锁定**时，右上角的 `⋯` 按钮会：

- 变成**锁图标** 🔒
- 变成**红色**

解锁之后，自动变回原来的三个点和默认颜色。

| 未锁定 | 已锁定 |
|:---:|:---:|
| ![未锁定](./images/normal.png) | ![已锁定](./images/pinned.png) |

**按钮照常能点**，只是图标和颜色变了，功能一点没少。

---

## 怎么用

不需要任何设置。

1. 打开一篇笔记
2. 锁定标签页 —— 右键标签选**锁定**，或者用命令面板里的**解锁/锁定**命令
3. 右上角的 `⋯` 变成红色锁图标
4. 解锁之后恢复正常

## 安装

### 从插件市场安装

**设置 → 第三方插件 → 浏览**，搜索 **Pin Indicator**。

### 手动安装

1. 从[最新 release](../../releases/latest) 下载 `main.js`、`manifest.json`、`styles.css` 三个文件
2. 在自己的库里建目录 `<你的库>/.obsidian/plugins/pin-indicator/`
3. 把三个文件拷进去
4. 重启 Obsidian
5. 在**设置 → 第三方插件**里启用 **Pin Indicator**

### 从源码安装

没有构建步骤 —— `main.js` 就是源码本身。照上面的方法拷三个文件即可。

## 原理

Obsidian 给每个视图都挂了 `view.moreOptionsButtonEl`（也就是右上角那个 `⋯` 按钮），标签页本身带一个 `pinned` 状态。

插件读这个状态，用 `setIcon` 换图标，再加一个 CSS class 染色。

监听三类事件：每个标签页自己的 `pinned-change`，以及工作区的 `layout-change` 和 `active-leaf-change`。另外在状态变化后还会补刷两次（150 毫秒和 600 毫秒），因为 Obsidian 自己的表头更新可能会把图标刷回去。

**不做轮询，不后台运行，不联网。**

### 为什么不做成 CSS 片段

Obsidian 只给**侧边抽屉**加了 `.is-pinned`。标签页本身没有对应的祖先 class，所以纯 CSS 选不到「已锁定标签页里的那个 `⋯` 按钮」。

`:has()` 在手机端不保证可用，不能依赖它 —— 这是硬约束。

---

## 关于名字

Obsidian 中文界面把这个功能叫**锁定**，英文界面叫 **Pin**，指的是同一件事：防止标签页被误关。

**这个插件本身不锁、也不保护任何东西**，它只负责把「已锁定」这个状态显示出来，让你一眼看见。

---

## 和其他插件的区别

市场上跟 pin 相关的插件有几十个，但**没有一个把原生锁定状态显示在当前笔记上**。

| 插件 | 它做什么 | 为什么不是一回事 |
|---|---|---|
| Pinned Tabs Customizer | 给锁定的标签换自定义图标 | 改的是**标签栏**，而且仅桌面端 |
| Pinned Tabs Row · Pinned Tabs · Shrink pinned tabs · Pinned Tab Utils | 改锁定标签的样子或行为 | 都在标签栏上 |
| Pin Enhancer · Pin Tab Guard · Real Pin | 防止锁定标签被误关 | 不显示状态 |
| Pins Save · Pinned Daily Notes | 重启后恢复锁定 | 不显示当前状态 |
| Pinned Files · Pinit · Pinup · Pin to Top · Star Pins · Folder Pin | 把文件固定到文件夹顶部 | 用的是**它们自己的一套列表**，跟原生锁定无关 |
| Pinned Notes · New Tab Pins | 固定到侧栏或启动页 | 同样是自己的列表 |

**Obsidian 自己在笔记标题栏里根本不显示锁定状态** —— 唯一的提示在标签栏，而手机屏幕上那个提示基本看不见。

这个插件读的是 Obsidian 自己的 `leaf.pinned` 状态，只把它反映到「更多选项」按钮上。**不存任何数据，也不维护自己的列表。**

## 兼容性

- 桌面端和手机端都能用（`isDesktopOnly: false`）
- 需要 Obsidian 1.4.0 或更高版本
- 无第三方依赖 —— `require` 只有宿主自带的 `obsidian` 模块
- 不联网、不收集数据、不读写文件系统
- 没有设置项，不保存任何数据

## 常见问题

**能防止笔记被关掉吗？**
不能。这个插件只负责显示锁定状态，防止标签被关是 Obsidian 自己的行为。

**多窗格（分屏）能用吗？**
能。每个标签页单独跟踪。

**解锁后锁图标会立刻消失吗？**
会。

**关掉标签后按钮还显示锁图标？**
不应该。每次布局变化都会重新判断。如果出现了，请提 issue。
